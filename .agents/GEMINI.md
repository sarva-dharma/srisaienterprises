# Project Agent Guide: Website (Sri Sai Enterprises Retail Store)

## 1. Overview
This project is a bilingual retail web application (Kannada: ಶ್ರೀ ಸಾಯಿ ಎಂಟರ್‌ಪ್ರೈಸಸ್ / English: Sri Sai Enterprises):
- `index.html`: Responsive e-commerce storefront with bilingual localization.
- `create_dummy_customers.py`: Seed data generation script creating dummy customer test accounts.
- `.nojekyll`: GitHub Pages static hosting compatibility.

## 2. Version Control Guidelines
- Active development branch: `main`.
- Use Conventional Commits (`feat:`, `fix:`, `style:`, `docs:`).
