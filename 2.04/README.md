# Sri Sai Enterprises (ಶ್ರೀ ಸಾಯಿ ಎಂಟರ್ ಪ್ರೈಸಸ್) - Version 2.04

## Overview
Version 2.04 is a clean, decluttered, high-readability architectural and civil drafting web application designed for both everyday Bengalurigas and institutional clients.

### Key Architecture & Features:
1. **Decluttered Single-Page Application (SPA)**:
   - Instant hash routing between 4 clean views:
     - `#services`: Interactive service tiles with search and category filtering.
     - `#about`: Founder profile (S M Thyagaraja, Draftsman Civil), 37+ years heritage, and registration credentials.
     - `#locate-us`: Office address in Gayathrinagar (Opp. More Retail Store), Namma Metro access, and interactive Google Maps.
     - `#enquiry`: Direct contact channels (Call & Email) + interactive enquiry form with pre-selection.
2. **Simple English & Familiar Bengaluru Terms**:
   - Everyday terms (e-Khata / e-Aasthi, Nambike Nakshe, PreDCR CAD blueprints, bank loan cost estimation, BBMP/BDA bylaws).
   - Clear layman explanations on every service tile.
3. **No WhatsApp Requirement**:
   - Replaced entirely with direct click-to-call phone buttons (`94480 54185` / `080 23325509`), direct email (`smthyagaraj@gmail.com`), and an enquiry form.
4. **Local Development**:
   - Running locally at `http://localhost:8085`.
5. **GitHub Pages Ready**:
   - Completely standalone static HTML, CSS, and JS with zero server build dependencies.
